# Site-owned social icon examples

The simple envelope and code-bracket SVGs are original geometric example artwork created by
Eureka for this fictional showcase. They are not vendor logos or part of Sidera's built-in icon
set. Replace these local assets and menu destinations with the site owner's own choices.
The appearance glyph is supplied separately by the theme under its existing third-party notices.

These files are retained historical source only. The normal showcase now selects
Solar email/code keys from the inline YAML registry; no runtime UI references
these standalone files. Removal requires separate approval, not this migration.
