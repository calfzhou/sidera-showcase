## Choose a bounded task

Set aside a short window for one piece of upkeep: checking a backup, replacing a broken link or writing down a command that was difficult to remember. Avoid turning a maintenance session into a redesign.

## Leave a stopping point

Record what changed and how it was checked. If the next task is larger than expected, leave a note rather than expanding the current session without a limit.
