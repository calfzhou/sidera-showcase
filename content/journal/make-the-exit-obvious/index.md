## Completion is part of the interface

A task is not finished merely because the operation succeeded. The person using the interface still needs to know what happened, where the result lives and whether anything else is required.

## Keep navigation honest

Previous and Next should follow a stable sequence. A parent link should describe a real relationship. A cancel control should not secretly save a partial action. These small promises make an interface easier to trust.

Together, the three parts of Quiet software describe a modest approach: a useful default, additional detail when needed, and a clear way to finish. None of them requires the interface to feel empty.
